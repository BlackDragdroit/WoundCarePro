# WoundCarePro

Wunddokumentation für zertifizierte Wundmanager:innen.

WoundCarePro hält fest, wo eine Wunde am Körper liegt, wie sie bei jedem Besuch aussah (Befund, Maße, Foto) und wie sie behandelt wurde, und erstellt daraus Berichte als PDF.

- Patient:innen, Wunden auf einer Körperkarte, eine Beurteilung pro Besuch
- Die Daten bleiben auf dem Gerät oder auf dem eigenen Server der Einrichtung
- Windows-App

## English

Wound documentation for certified wound care specialists.

WoundCarePro records where a wound is on the body, what it looked like at each visit (findings, measurements, photo) and how it was treated, and produces PDF reports from that.

- Patients, wounds placed on a drawn body, one assessment per visit
- The data stays on the device or on the organisation's own server
- Windows app
