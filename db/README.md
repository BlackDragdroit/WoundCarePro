# WoundCarePro - DB Setup & Migration (Local & Synology DS224+)

This folder contains resources to run **MariaDB** locally for development and migrate your local-first JSON data to a production instance running on your **Synology NAS (DS224+)**.

## File Overview

- `schema.sql`: Contains the complete SQL structure (`patients`, `wounds`, `assessments`, `body_regions`) optimized for MariaDB/MySQL.
- `docker-compose.yml`: Launches a local MariaDB container on port `3306` with preconfigured development credentials.
- `migrate.js`: Node.js utility to compile your JSON database (retrieved from decrypted exports) into standard `INSERT` statements for SQL databases.

---

## 1. Local Development (Docker)

To run the database locally using Docker:

1. Open a terminal in this `db` directory.
2. Run:
   ```bash
   docker compose up -d
   ```
3. Docker will download the MariaDB image and start a server on port **3306**.
4. The tables defined in `schema.sql` are created automatically on the first startup.

### Development Connection Details:
- **Port:** `3306`
- **Database:** `wound_care_pro`
- **Username:** `wound_user`
- **Password:** `wound_password_2026`
- **Root Password:** `root_security_pass`

## 2. Syncing App Data to MariaDB

When you make updates in the React/Tauri frontend, your data is stored locally in encrypted format (complying with GDPR requirements). To import it into the MariaDB database:

1. **Export database from the App:**
   - In the app header menu, click **"Datenbank exportieren"**.
   - Save the file on your computer. (If you use the File System API, download the unzipped `.json` file. If default download, extract the `.zip` file to get `database.json`).
   - *Note: Exported files are decrypted on download so they can be parsed by migration scripts.*

2. **Run the migration compiler:**
   - Navigate to the `db` folder in your terminal.
   - Execute:
     ```bash
     node migrate.js <path_to_decrypted_database.json>
     ```
   - This creates an `import.sql` file in this directory.

3. **Load the SQL file into MariaDB:**
   - Run the following command in terminal:
     ```bash
     docker exec -i woundcare_mariadb mysql -u wound_user -pwound_password_2026 wound_care_pro < import.sql
     ```
   - Alternatively, open your DB client (e.g. phpMyAdmin, DBeaver, TablePlus), connect, and execute/import `import.sql`.

## 3. Deploying to Synology NAS (DS224+)

There are two primary ways to set up MariaDB on a Synology DS224+:

### Option A: Via Container Manager (Docker) - Recommended 🚀
Since the DS224+ supports Docker, you can run the exact same container setup:
1. Open **Container Manager** on DSM (Synology's Operating System).
2. Go to **Project** -> Click **Create**.
3. Select a folder on the NAS, enter a project name, and paste the contents of `docker-compose.yml`.
4. Upload `schema.sql` into the same folder on the NAS so DSM can find it.
5. Click **Next** to deploy. Container Manager will instantiate the database, auto-creating the tables.
6. Open port `3306` in your Synology Firewall configuration if you want other devices in the home network to connect to it.

### Option B: Via Package Center (Native Synology Package)
1. Open **Package Center** on DSM.
2. Search and install **MariaDB 10**.
3. Open the installed MariaDB 10 app, verify port is set to `3306` (or another port), set a root password, and check "Log remote connection" if needed.
4. Open **phpMyAdmin** (install via Synology Package Center if not present).
5. Log in to phpMyAdmin, go to **SQL**, paste the contents of `schema.sql` to generate the database and tables.
6. To sync data, use the phpMyAdmin **Import** tool and upload `import.sql` generated by step 2 of this guide.
